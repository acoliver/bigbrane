P4 SELECTED CASES (these rules refine the solvable-case rule of PROFILE SLOTS above). A P4 slot asks for one solvable case per task: the statement fixer selects one size at or below the profile's ceiling, and the slot holds when the mechanism learns that case. The ceiling bounds the choice; it is not a requirement to learn every size up to it. P2, not P4, is held to every listed size.

A P4 statement carries `profile_slot.selected_case` (the selected size, m, the seeds and the threshold), `profile_slot.size_ceiling` (the largest size the profile allows) and `instantiated_claim`, the slot's claim with that case filled in. Compare the formal statement with `instantiated_claim`, read with the definitions it uses. A selected size at or below the ceiling is not a difference in domains, constants or quantifiers. A different task, a size above the ceiling, a different m, fewer seeds, a lower threshold, a missing data control or a learning rule other than the card's are differences.

P4.composition is satisfied by either variant: two-hop lookup at a selected table size, or variable binding at a selected chain length. `profile_slot.part` names the variant this statement covers; compare it with that variant only.
