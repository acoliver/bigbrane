## Parity disjoint sets: supported

Source: [CP-Algorithms, Disjoint Set Union, parity and union-by-size sections](https://cp-algorithms.com/data_structures/disjoint_set_union.html#support-the-parity-of-the-path-length-checking-bipartiteness-online). Its displayed edge formula is `t=x XOR y XOR 1`; for a supplied XOR constraint `s`, replace the edge's unit parity by `s`. This follows by composing the potentials along the joined path.

Maintain parent potentials `l_i = x_i XOR x_parent(i)`. Find returns root `r_i` and potential `a_i = x_i XOR x_r_i`. A constraint `(u,v,s)` merges different components with `l_root = a_u XOR a_v XOR s`. Equal roots require `a_u XOR a_v = s`; any violation sets a sticky global inconsistency flag. Union by size and path compression change representation without changing these equations. A query returns the relative potential for connected vertices in a consistent stream, and otherwise the stipulated uniform answer. Non-query tokens return uniform answers. The token protocol only encodes constraints and queries arithmetically; it does not select a transition function. Parameter `vertices` is any positive integer. There are no learned parameters or limiting repairs.

The host checks output distributions. Captured parent/label/size states are retained separately, because path compression and tie-breaking need not agree internally. An exhaustive Boolean-assignment test provides an additional oracle independent of both DSU implementations.

## PGL version space: supported with explicit empty-space protocol

Sources: Mitchell, *Machine Learning* (1997), [chapter 6 lecture slides](https://www.cs.cmu.edu/afs/cs/project/theo-20/www/mlbook/ch6.pdf), printed slides 130-132 and 143, specifies consistency likelihood and posterior averaging. Jeffrey Steif, [*Lecture Notes on Jordan's Theorem*, section 4.1, Theorem 4.1](https://www.math.chalmers.se/~steif/group.lectures.pdf), specifies the sharply three-transitive projective action.

For prime `p >= 3`, enumerate invertible two-by-two matrices over `F_p` modulo nonzero scalars, acting by `g(z)=(az+b)/(cz+d)` on `F_p union {infinity}`. The initial hypothesis set has `(p+1)p(p-1)` elements. List-then-eliminate updates `H <- {g in H: g(x)=y}` on a completed labeled pair. A uniform prior and noiseless observation model give `P(v|x,D)=sum_{g in H} 1[g(x)=v]/|H|`. The active query maximizes predictive entropy, choosing the smallest label on ties. Passive query positions emit the uniform token distribution. These protocols do not modify hypothesis elimination or Bayesian arithmetic.

The source card explicitly prescribes uniform predictions and query zero when `H` is empty. Those are external abstention conventions, not a defined Bayesian posterior on zero-probability data. They must remain documented as such. No claim of a posterior on inconsistent data is made. A separately written interpolation-free enumeration checks all saved active/passive streams, including the abstention branch. Prime and mode are free configuration; no learned matrix is frozen. The mapping uses a specified finite projective group, never an arbitrary transition table supplied by the card.

## Nested concepts and the size principle: conditional only

Source: Tenenbaum and Griffiths, [*Generalization, similarity, and Bayesian inference* (2001)](https://cocosci.princeton.edu/tom/papers/TGbbs.pdf), equations 1-5 and multiple-example discussion. For a nested family `h_r={y: score(y)>=r}`, asserted volume `|h_r|=exp(-delta*r)`, exponential prior density proportional to `exp(-lambda*r)`, `k` positive examples, and negative examples treated as membership exclusions, the posterior density is proportional to `exp((delta*k-lambda)*r)` on `h<r<=g`, where `g=min(positive scores)` and `h=max(0,negative scores)`. Query membership integrates this density up to the query score. The host integrates on the feasible interval using Gauss-Legendre quadrature, independently of the card's closed-form exponential ratio.

The score table is a fixed feature parameter, not a memory-selected transition. The host requires finite nonnegative scores, positive delta, positive lambda (lambda zero would be an improper uniform-prior limit and is refused), and rejects empty feasible intervals. It does not implement the card's point-mass fallback there. The saved original comparator skipped those queries; they remain unverified. Moreover the exponential volume model and first-positive anchor convention are assumptions, not proven consequences of the learned hyperbolic embedding. Agreement on feasible evidence is conditional arithmetic, not a full reduction or restored death code. This operation is retained for diagnosis and is not bound into historical Phase7 acceptance.

## SUGS regression allocation: independently test the actual published likelihood

Source: Wang and Dunson, [*Fast Bayesian Inference in Dirichlet Process Mixture Models* (2011)](https://pmc.ncbi.nlm.nih.gov/articles/PMC3812957/), equations 2.3 and 3.1, section 3.1 algorithm. The allocation maximizes `log n_j + log posterior_predictive(y|x,j)` versus a new cluster with `log alpha`. For independent output dimensions of Bayesian linear regression with known variance `sigma2`, prior precision `lambda*I`, and weighted observations, posterior sufficient statistics are `A_j=lambda*I+sum beta*x*x^T`, `B_j=sum beta*x*y^T`, `M_j=solve(A_j,B_j)`. With a new observation of noise variance `sigma2/beta`, its predictive covariance is `sigma2*(1/beta+x^T solve(A_j,x))*I`. Thus its log density, omitting only common constants, is `-d/2*log(c_j)-||y-M_j^T x||^2/(2*sigma2*c_j)`. Select the maximizing existing/new cluster, then add that observation to its sufficient statistics.

Inputs are accepted, input-gated key/value pairs and their positive weights. The host retains the determinant term and has no fixed cluster cap. It returns allocation indices. This is a necessary subcomparison, not a claim that the card's last-cluster readout is the published mixture predictive. The original saved comparator drops the determinant and caps the number of clusters. Neither modification will be added to this host to recover a death code. All gate and embedding parameters in the original draws remain free; the inputs are captured from that original program.

## Recursive HMM: not yet bound

Source: Cappé, [*Online EM Algorithm for Hidden Markov Models* (2011)](https://hal.science/hal-00410106v2/document), Algorithm 1, equations 8-10.
