Read originals in place; no cache copies, local index writes, network, model calls or acceptance reruns. Missing files are reported, never fetched. All output stays here. Use main .venv-hybrid Python with sibling cwd and PYTHONPATH. Exact original queries, source order, limit 6, retries and acceptance gates remain unchanged.

## Predeclared extraction

1. For the four pinned first queries and all 72 saved contexts, reconstruct request parameters using the actual adapter builders. Compare public parameters to saved raw envelopes and ordered parsed IDs to receipts. Retain query SHA, card, source, field/lens, round, source-order position, ASCII arXiv tokens, conjunction AST, local FTS expressions, page/start/offset and explicit sort. OpenAlex/S2 pass strings unchanged; provider-internal tokenization, default ordering and boolean/full-text scope are unknown unless evidenced in existing source. No external documentation fetches.
2. Parse actual response structures: Atom OpenSearch totalResults/startIndex/itemsPerPage including namespaces; OpenAlex meta.count/page/per_page; S2 total/offset/next. Missing totals remain unknown, never zero. Distinguish explicit zero pools, exhausted nonempty windows, more results outside the returned page, and unknown. HTTP 200 alone is not matching evidence. Separate failed/cooldown, cache-read historical evidence, local receipts and fresh observed transport. Redirect/error bodies are not pools. Compare raw entry counts to parsed counts.
3. Generic metrics, computed without registered labels: token count and removed stopwords; local all/any expressions; title/abstract literal token coverage among saved returned records; abstract presence; result and total counts by source/field/round; unique-query support with within-query dedup and discovery-order ties; initial five-seed source/query/lens distribution; seed/query overlap and raw bibliography edges to selected seeds and acquired records. Coverage is an ASCII case-folded token-set diagnostic, not provider eligibility. Card-token overlap uses saved original card text only, is descriptive, and does not define relevance. No choice of metrics or query alterations based on target matches.
4. Separately annotate all 11 registered works with earliest explicit saved trace using existing offline/raw audit/replay evidence. Compare preexisting exact-lookup/local metadata to literal query tokens. Missing title/abstract terms cannot disprove remote arXiv all-field matching, which may cover fields unavailable here; never infer lack of indexing from an absent hit. Reuse existing local FTS proof rather than rerun full index eligibility. Identify raw bibliography-only paths separately from fetched records, candidates, ranking and exposure.
5. Run only new extraction tests and optionally the unchanged seven transport tool tests. Cover namespaces/alternate fields/missing totals, zero/exhausted/more pools, exhausted failures/cooldown/redirects, attribution/error projection and secret-free outputs. Disable socket connections during analysis/tests. Hash originals and supplemental inputs again, retain rerunnable structured results and report limitations.
