## Input contract

`synthetic.py` is a runnable schema example, explicitly invented and unsuitable as a study corpus. Each pool is `{payload, sha256}`. SHA-256 covers sorted compact UTF-8 JSON with Unicode preserved. The payload contains exactly card_id, arm, metadata, acquisition_id, calls, blobs and evidence. Metadata contains only concept and four ordered lenses, each with name and three phrases. Unexpected target-title, target-ID and free-form boolean fields are rejected. Text provenance and target blinding still require external human work.

Each call has exact card/arm/sequence ownership, operation, query_index, lens, query_sha, source, request, seed, limit, records, returned_count, outcome, error, attempts, exchanges, request_count, response_count and body_sha. Search calls are in query/source order. Expansion calls must follow selected seeds, references then citations, and use the deterministic S2 lookup. Public parameters include the original SELECT/FIELDS projections and first-window size. S2 and semantic_scholar are an explicit source alias pair. Returned identities carry source/source_id and optional title, arxiv_id, doi and explicit aliases. No arbitrary identity boolean is accepted.

A successful call's body_sha points to an immutable normalized blob containing exactly request and records. This is a replay receipt hash, not a raw provider-body hash or proof of a network observation. Future acquisition must retain original provider envelopes and transport provenance separately, then construct these arm-specific normalized receipts without inventing results. Blobs and pool content hashes are checked; supplied histories remain external evidence. Changing requests requires fresh acquisition. No network client is present here.

Outcomes are network, cache, cooldown, unavailable or error. Zero-network outcomes require zero attempts/exchanges. A network success requires a final 2xx response. Consecutive exchanges within an attempt require redirect status; attempts are contiguous and capped at four. Requests, responses, redirects and retries remain separate from logical slots. Empty answered windows remain empty. The first terminal failure stops consumption, and extra or absent calls fail validation. Unresolvable seeds require unavailable receipts.

Identity union merges source IDs, normalized titles, arXiv IDs/versions, DOI aliases and declared cross-provider aliases, retaining the earliest discovery. Seed ranking counts distinct query indices, never repeated appearances. Balanced selection assigns each identity only once to its least-used supported lens/query/source stratum. Exposure reserves a representative per field, fills by baseline rank and returns rank order. Equal normalized titles are an explicit merge assumption and can conflate distinct works; unresolved aliases can split one work. Results preserve these limits rather than asserting exact global work counts.

## Metrics and pilot decision

Acquired, expansion-returned, fetched, exposed and reference-used metrics are separate. Acquired/expanded identities are projected through known alias unions. Fetched/used entries require a unique acquired identity and a content-addressed artifact containing stage, identity and nonempty text. Used identities must also be exposed. Empty or absent evidence remains unknown. Artifact text is externally supplied evidence, not automatically verified semantic relevance, full-document completeness or exhaustive usage. Those stage coverages are evidence-supported lower bounds. No full-text fetch or model call occurs in this run, and optional later evidence does not authorize extra acquisition operations.

Externally created relevant-reference identities form the frozen denominator, deduplicated by the same explicit identity rules. A zero denominator fails. All ratios are bounded by that denominator. Transport availability uses answered/consumed logical calls and has no semantic interpretation. The factorial output reports fixed-factor contrasts, averages, interaction, complete-card counts, incomplete counts and zero-recovery sensitivity accounting over all 12 cards. Bootstrap intervals and exact sign-test counts use cards, never result positions. The pilot is not a power analysis.

Further-testing eligibility requires positive means at both fixed factors, a positive lower uncertainty bound, complete transport pairs and nondecreasing evidenced usage. Nonpositive fixed-factor means falsify the broad pilot improvement claim; missing evidence or transport makes eligibility inconclusive. Evidence authenticity and completeness need future validation. This harness never authorizes automatic rollout or changes acceptance.
